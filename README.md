# Bootstrap Tasks

A collection of small Bootstrap practice tasks. Each task uses Bootstrap classes with very little custom CSS.

## Tasks

| No | Task | What it covers | File |
| -- | ---- | -------------- | ---- |
| 1 | Home Page | navbar, carousel, cards and footer | `task1.html` |
| 2 | Template | a full ready-made page layout using Bootstrap | `template.html` |
| 3 | Typography | headings, display text, lead, text colors, alignment | `typography.html` |

(Change the file names if yours are different.)

## How to Use Bootstrap

Add this inside `<head>`:

```html
<link
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
  rel="stylesheet"
/>
```

Add this before `</body>` (needed for the navbar toggle and carousel):

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

## How to Run

Open the `.html` file with Live Server or in the browser. Internet is needed for the CDN links.
